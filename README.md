# Constructora E&A

Sitio web estático de Constructora E&A.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `constructora-ea`.
2. Sube todos los archivos y carpetas de este proyecto; `index.html` debe quedar en la raíz.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

## Archivos

- `index.html`: página principal.
- `assets/`: logotipo y fotografías utilizadas por la página.

## Nota sobre las imágenes

La galería incluye imágenes ilustrativas y testimonios ficticios generados como ejemplo. No deben presentarse como proyectos realizados ni opiniones reales de clientes. Sustitúyelos por fotografías y reseñas auténticas antes de promocionar la empresa.
